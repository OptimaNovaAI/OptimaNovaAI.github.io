    Move a Project From Personal to DCBF

    Instructions and context carry over through Claude itself. Files get re-uploaded. Plan on about 15 minutes a project.

    You are on
    1 of 9
    Get the Handoff
    Personal ClaudePrivate window
    DCBF WorkspaceRegular window
    Before You Start. Open your personal Claude in a private window and your DCBF workspace in a regular one, so you always know which is which. Have Dropbox open. Some originals live there.
    1. Step 1

      Get the Handoff

      In your personal account, open the project and start a new chat inside it.

      Give me a handoff summary and an index of this project, including every file I have uploaded.
    2. Step 2

      Get the Setup Prompt

      Give me the prompt I will use to set up this project in my DCBF Claude workspace. Include links to every file in this project that should be ported over.
    3. Step 3

      Gather the Files

      Give me a PowerShell script that copies these project files into one folder on my desktop, so I can move them into the new project. Ask me if anything is unclear.

      Copy the script. Open Start, type PowerShell, and select Open. Skip Run as Administrator, which asks for a password you do not need. Right-click inside the window to paste, then press Enter.

    4. Step 4

      Close the Gaps

      If files are missing, screenshot the PowerShell result, switch the chat to Opus 5.5, paste the screenshot, and ask:

      These are the only files that moved over. What's the plan?

      Claude can package the copies it holds into one zip. Download it. Expect two gaps: emails dragged in from Outlook were never files on your computer, and anything Claude holds only as text needs its original from Dropbox.

    5. Step 5

      Get the Instructions

      Give me the project knowledge instructions in copy-paste format.

      Copy the result.

    6. Step 6

      Create the Project in DCBF

      Switch to your DCBF workspace and confirm DC Bar Foundation at the bottom left. Select Projects, then New project. Name it using the convention below, keep visibility private, and create it.

    7. Step 7

      Paste the Instructions

      Open the project, select Instructions, paste, and save.

    8. Step 8

      Upload the Files

      Right-click the zip and select Extract All. Folders do not upload, so open each folder, press Ctrl+A, and drag the files into the project. The plus sign, then Upload from device, works too.

    9. Step 9

      Pin and Test

      Pin the project. Start a chat inside it and ask:

      Give me five bullet points on what you understand about this project.

      Correct anything that is off, especially names, dates, and numbers.
